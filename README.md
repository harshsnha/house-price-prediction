# House Price Prediction using Data Analytics with AI

Project for the **AICTE | IBM SkillsBuild Data Analytics with AI Internship 2026 (BharatCares)**.

The project cleans a housing dataset, explores it, trains and compares five regression models, picks the best one and serves it through a small Flask web app where you enter property details and get an estimated price.

## Project description

- Input: city, area (sqft), bedrooms, bathrooms, age, location score (1-10), parking spots
- Output: estimated house price in INR
- Best model is chosen by 5-fold cross-validated R2 and saved with Joblib
- AI-assisted coding tools were used during development for code generation, debugging and report drafting

## Dataset

`data/house_price.csv` has 1500 rows and 8 columns (`city`, `area_sqft`, `bedrooms`, `bathrooms`, `age_years`, `location_score`, `parking`, `price`).

The file is generated by `data/generate_data.py` (synthetic data with realistic price patterns and a few missing values), so it is already included in this repository. To use a real dataset instead, replace the CSV with your own file that has the same columns.

Dataset link: this repository, `data/house_price.csv`

## Technologies used

Python, Pandas, NumPy, Matplotlib, Scikit-learn, Joblib, Flask, HTML/CSS/JavaScript, Jupyter Notebook, python-docx

## Project structure

```
backend/app.py                  Flask API (/predict, /meta)
frontend/index.html             web form
data/generate_data.py           creates the sample dataset
data/house_price.csv            dataset
notebooks/                      full analysis notebook
model/                          saved model + metrics.json
report_images/                  charts used in the report
analysis.py                     EDA charts
train_model.py                  trains, compares and saves the model
generate_report.py              builds the Word and HTML report
make_submission.py              prepares the files for the internship form
requirements.txt
```

## Setup and run

```bash
pip install -r requirements.txt

python data/generate_data.py     # skip if you already have the CSV
python analysis.py               # EDA charts
python train_model.py            # train, compare, save model
python backend/app.py            # start the web app
```

Open http://127.0.0.1:5000 in the browser.

To open the notebook: `jupyter notebook notebooks/house_price_analysis.ipynb`

To build the report and the submission files:

```bash
python make_submission.py --name Your_Name --college "Your College Name"
```

## Results

| Model | R2 (test) | CV R2 | MAE (INR) |
|---|---|---|---|
| Gradient Boosting | 0.981 | 0.961 | ~5.5 lakh |
| Random Forest | 0.974 | 0.951 | ~6.3 lakh |
| Linear Regression | 0.943 | 0.922 | ~9.6 lakh |
| Ridge | 0.943 | 0.922 | ~9.6 lakh |
| Lasso | 0.943 | 0.922 | ~9.6 lakh |

Scores are high because the data is synthetic; real market data will score lower.
